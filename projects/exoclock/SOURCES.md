# Sources: Exoplanet Transit Analysis (ExoClock)

Page built: 2026-10-12. Not linked from the website.

## Angle (from Angelos, 2026-10-12)

The page should **promote ExoClock**, not show how much Angelos did. The main
message: you can contribute to real science without being a trained
professional, and amateur astronomers can help. That's why the page is built
in this order: the idea, what ExoClock does, the evidence that it works, the
steps to join, and only then a short "What we did".

## Where each fact came from

| Fact on the page | Source |
|---|---|
| 2024, two-student group, supervisor Ioannis Gkolias, first exoplanet work, observed a known transit, relative photometry, submitted light curve | `PROJECT_NOTES.md` (working draft) |
| ExoClock monitors ephemerides; run by the Ariel Ephemerides Working Group; supports Ariel | https://www.exoclock.space/ (checked 2026-10-12) |
| Ariel will study about 1000 exoplanets | exoclock.space homepage ("about 1000 extrasolar planets") |
| Open to anyone with "a telescope and a CCD or CMOS camera"; quotes "everyone can contribute to real research…" and "can contribute significantly and make a difference" | exoclock.space homepage |
| Five steps (register telescope, schedule, observe, analyse with HOPS or other software, upload, review then publication); ExoWorlds Spies guidelines | https://www.exoclock.space/contribute |
| Project IV: ~30,000 measurements, 620 planets, 45% needed an update; co-authorship for anyone contributing even one observation; title of the first paper | https://www.exoclock.space/publications |
| Transit animation | Drawn for this page. Schematic only, depth exaggerated, labelled as "not real data" |

The NASA/JPL animation suggested in `PROJECT_NOTES.md` was **not** used. A
small custom animation in the site's style is used instead.

Note: the publications page still lists Project IV as a preprint "submitted to
ApJS", while `PROJECT_NOTES.md` cites it as published (ApJS 283, 5, 2026). The
page links to ExoClock's publications page and does not name the journal.
